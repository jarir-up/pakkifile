# ADR-0053: qpdf to password-protect synthetic statements

- Status: Approved
- Approved by: Muhammad Jariruddin, 2026-11-10

## Context
FR-10 requires reading password-protected PDF statements, which Pakistani banks commonly send. Testing that needs protected synthetic PDFs, and poppler (ADR-0044) can read them but not write them.

## Decision
The synthetic generator uses the `qpdf` command-line tool (Apache-2.0, in Ubuntu's package archive) to encrypt the PDFs it writes. Parsers open protected files with `pdftotext -upw`, using the password the applicant types; it is never stored.

## Consequences
CI and development machines install `qpdf` alongside `poppler-utils`. The applicant's machine needs only poppler.
